为什么很多人没遇到

这个 bug 主要在以下组合下出现：

  • Windows
  • Python 3.14
  • 本地向量库
  • 本地 GGUF embedding 模型

大多数用户使用的是：

  • Linux + Docker
  • 云端 embedding API
  • 云端/托管向量数据库
  • 较旧的 Python 版本

所以这条本地路径测试覆盖较少。
